Cara mendapatkan Page ID & Token (sekali sahaja)

  1. Log masuk developers.facebook.com dengan akaun FB yang menjadi admin Page. Klik My Apps → Create App, pilih jenis Business.
  2. Buka Tools → Graph API Explorer. Pilih app tadi. Di Permissions, tambah: pages_show_list, pages_read_engagement, pages_manage_posts. Klik Generate Access Token dan benarkan Page.
  3. Buka Tools → Access Token Debugger, tampal token tadi, klik Debug, kemudian Extend Access Token. Salin token panjang (long-lived).
  4. Kembali ke Graph API Explorer, tampal token panjang itu, jalankan GET me/accounts. Salin id (Page ID) serta access_token (Page Access Token).
  5. Tampal kedua-duanya di atas dan klik Simpan & Uji Sambungan. Nama Page akan dipaparkan jika berjaya.
Token disimpan dalam Script Properties (bukan dalam Sheet atau kod) dan tidak dipaparkan semula.
